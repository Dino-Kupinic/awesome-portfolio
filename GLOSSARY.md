# Awesome Portfolio

A curated list of personal portfolio websites, browsable by the technologies they are built with.

## Language

**Portfolio**:
One listed entry: a person's publicly accessible personal portfolio website.
_Avoid_: Site, entry, submission

**The site**:
The Awesome Portfolio website itself, where Portfolios are browsed.
_Avoid_: Portfolio (for this project's own website)

**Author**:
The person whose Portfolio it is.
_Avoid_: Owner, contributor (a contributor may add someone else's Portfolio)

**URL**:
The public address where a Portfolio can be visited.
_Avoid_: Live, link, demo

**Tech Stack**:
The technologies a Portfolio is built with, each named from the fixed list of Technologies.
_Avoid_: Tags, stack, tools

**Technology**:
One named item a Tech Stack can contain, spelled exactly as in the fixed list (e.g. `Tailwind CSS`).
_Avoid_: Tag, framework, library

**Screenshot**:
An automatically captured image of a Portfolio's URL, shown on the site.
_Avoid_: Preview, thumbnail
